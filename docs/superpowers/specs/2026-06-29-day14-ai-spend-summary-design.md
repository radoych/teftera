# Day 14 — AI Spend Insights (Gemini Natural-Language Summary)

**Date:** 2026-06-29
**Status:** Approved design, ready for implementation plan
**Build plan:** Day 14 (Phase 5 — Intelligence)

---

## Goal

Show a 2-3 sentence natural-language summary of the household's current-month spending
at the top of the Insights screen, generated by Gemini. It is cached for the session,
regenerated only on pull-to-refresh, and silently hidden if generation fails.

## Context — what already exists

- `app/(app)/insights.tsx` already renders a **static** "AI обобщение" block: a left accent
  line (`bg-surface-tint` at 30%), a `auto-awesome` sparkle icon, a `SectionLabel`, and a
  hardcoded Bulgarian paragraph. This day replaces the hardcoded text with real data.
- `services/gemini.ts` is the LLM chokepoint. It now uses `gemini-2.5-flash` and has
  `isRetryableGeminiError` + a retry loop (added in the receipt-extraction fix). Reuse both.
- Pure aggregation helpers exist: `sumCents`, `categoryBreakdown` (`features/transactions/dashboard`
  re-exported), `topMerchants`, `filterByRange`, `comparisonRange`, `pctChange`, `filterByUser`.
- `formatCurrency` formats integer cents as `€…` (bg-BG).
- `<Screen>` supports `refreshing` / `onRefresh` (the dashboard uses it for pull-to-refresh);
  Insights currently passes neither.
- `useTransactionsStore` holds `transactions`, `categories`, `loaded`.

## Locked decisions (owner policy)

1. **Fixed scope: current-month, household.** The summary ignores the Insights range pills
   and the Аз/Домакинство toggle — always current calendar month, all household members.
2. **Session cache.** Generated once per app session on first Insights view; held in a
   Zustand store; cleared on app restart (in-memory only, not persisted).
3. **Manual refresh only.** Pull-to-refresh regenerates. Adding a transaction, switching
   tabs, or toggling range/person does NOT regenerate.
4. **Hide on failure / no data.** If Gemini fails, returns empty/over-long text, or there is
   no current-month spend, the entire AI-summary block renders nothing (no error UI).
5. **Model `gemini-2.5-flash`** with the existing transient-retry; best-effort (never throws).
6. **Plain-text Bulgarian output** (no JSON, no markdown).

## Components (one responsibility each)

**`features/insights/summaryInput.ts`** (pure, tested):
- `interface SummaryInput { monthTotalCents: number; prevMonthTotalCents: number;
  pctChange: number | null; topCategory: { name: string; totalCents: number } | null;
  topMerchant: { merchant: string; totalCents: number } | null }`
- `buildSummaryInput(txs: Transaction[], categories: CategoryLite[], now?: Date): SummaryInput`
  — uses `filterByRange(txs, 'this_month', now)` for the month set and, for last month,
  `const c = comparisonRange('this_month', now); filterByDateBounds(txs, c.startISO, c.endISO)`;
  `sumCents` for both; `pctChange` for the delta; `categoryBreakdown(monthTxs, categories)[0]`
  for the top driver; `topMerchants(monthTxs, 1)[0]` for the top merchant. Caller passes the
  already household-filtered txs (`filterByUser(transactions, null)`).

**`services/gemini.ts`** additions:
- `buildSummaryPrompt(input: SummaryInput): string` (pure, tested) — assembles the
  instruction + the pre-formatted lines (amounts via `formatCurrency`). Lines for last month
  and top category/merchant are included only when present.
- `generateInsightsSummary(input: SummaryInput): Promise<string | null>` — builds the prompt,
  calls `gemini-2.5-flash` through the shared retry loop, returns the trimmed text. Returns
  `null` when not configured, on any error, or when the trimmed text is empty or longer than
  400 characters (a runaway response). Plain text — no JSON parse.

**`features/insights/summaryStore.ts`** (Zustand, the session cache):
- State `{ status: 'idle' | 'loading' | 'ready' | 'error'; text: string | null }`
  + `setLoading()`, `setReady(text)`, `setError()`, `reset()`. Initial `status: 'idle'`.

**`features/insights/summary.ts`** — orchestrator:
- `refreshSummary(txs: Transaction[], categories: CategoryLite[], deps?): Promise<void>` —
  sets `loading`, builds input, calls `generateInsightsSummary`; on a non-null string →
  `setReady(text)`, otherwise `setError()`. Never throws (wrapped). `deps` defaults to the
  real `generateInsightsSummary` + the store setters; tests inject fakes (mirrors
  `saveReceiptTransaction` / `runDetection`).

## UI wiring (`app/(app)/insights.tsx`)

- Read `summaryStore` (`status`, `text`).
- **First-generation trigger:** when `loaded && status === 'idle'` and there are transactions,
  call `refreshSummary(filterByUser(transactions, null), categories)` once.
- **AI-summary block render:**
  - `status === 'loading'` → the accent line + sparkle + label, with a `Skeleton` line where
    the text goes.
  - `status === 'ready'` (and `text`) → the real text.
  - `status === 'error'` / `'idle'` with no text → render nothing (whole block hidden).
- **Pull-to-refresh:** add `refreshing` + `onRefresh` to `<Screen>`; `onRefresh` runs
  `refreshTransactions(householdId)` then `refreshSummary(filterByUser(latestTxns, null),
  categories)` (force regenerate from fresh data). A local `refreshing` boolean drives the
  spinner, mirroring the dashboard.

## Data flow

```
Insights mount (loaded, status 'idle', data present)   OR   pull-to-refresh
        │
        ▼
refreshSummary(householdTxs, categories)            householdTxs = filterByUser(txns, null)
  buildSummaryInput → buildSummaryPrompt → generateInsightsSummary (2.5-flash + retry)
        │ string                              │ null
        ▼                                     ▼
  store.setReady(text)  → block shows    store.setError() → block hidden
```

## Prompt shape (illustrative)

```
Ти си финансов асистент. На база данните по-долу за текущия месец напиши кратко
обобщение от 2-3 изречения на български. Само обикновен текст, без markdown.

Общо този месец: €820,00
Миналия месец: €730,00 (с 12% повече)
Най-голяма категория: Хранене (€310,00)
Топ търговец: Kaufland (€140,00)
```
Amounts are pre-formatted with `formatCurrency`, so the model never does arithmetic.

## Testing (TDD)

Pure logic and the orchestrator are unit-tested; the Zustand store, the screen, and the
network call are not (per project convention).

- `features/insights/summaryInput.test.ts`: `buildSummaryInput` → correct total, prev-month
  total, `pctChange`, top category, top merchant from fixtures; `pctChange` null when there is
  no last-month spend; null top category/merchant for an empty current month.
- `services/gemini.test.ts` (append): `buildSummaryPrompt` includes the formatted total, the
  MoM line, top category, and top merchant; omits the last-month / category / merchant lines
  when those inputs are null.
- `features/insights/summary.test.ts`: `refreshSummary` with injected fakes → sets `loading`
  first; a string result → `status: 'ready'` + text; a `null` result → `status: 'error'`; a
  thrown error in the generator is swallowed → `status: 'error'` (never rejects).

## Out of scope (v1)

Anomaly mentions in the narrative; following the range/person toggle; persisting the summary
across app restarts; non-Bulgarian localization; streaming the response.

## Checkpoint

Open Insights with real current-month spend → a 2-3 sentence Bulgarian summary appears (after
a brief loading line). Switching tabs and back does not re-call Gemini (cached). Pull-to-refresh
regenerates it. With the Gemini key removed or no spend, the summary block is simply absent —
no error, no crash.
